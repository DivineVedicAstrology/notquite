# notquite

Portfolio of Rahul Sharma. Not quite photographs. Not quite paintings. Not quite reality.

**real enough to believe.**

Cinematic editorial reel for an AI-Artist Creative Director. Filter the work (Surrealism, Glitch, Psychedelic, UGC). Exclusive luxury UGC for founders.

- Site repo: [DivineVedicAstrology/notquite](https://github.com/DivineVedicAstrology/notquite)
- X: [@RahulAiArt](https://x.com/RahulAiArt)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:8080](http://localhost:8080).

```bash
npm run build
npm run typecheck
```

## Stills

Place JPEG stills in `public/art/`:

- `rahul-hero.jpg` (hero)
- `rahul-portrait.jpg` (About)
- project stills matching `src/lib/data/projects.ts` (`brb.jpg`, `quiet.jpg`, `mask.jpg`, …)

Until those files are in the repo, the reel layout still runs. Images 404 until you drop them in.

If you have `notquite-github.zip` from Grok, copy `public/art/` from that zip into this folder.

Custom domain comes later. This repo is the source of truth for **notquite**.
